# SyncText

A fast and secure real-time collaborative text editor.

## Features

- Real-time multi-user editing
- Multi-tab support
- Code Mode and Text Mode
- Save projects to Google account
- Dark and Light theme
- Mobile responsive
- QR code room sharing

## Tech Stack

- React
- Tailwind CSS
